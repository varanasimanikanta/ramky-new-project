# Ramky Foundations

Create a modern, professional, corporate website for Ramky Infrastructure, an infrastructure and development company in India.

Website Goal

Build a trustworthy and premium-looking website that presents the company, its infrastructure projects, services, employees, achievements, and career opportunities. The website should be suitable for clients, employees, job seekers, investors, and business partners.

Design Style

Professional corporate design

Modern and clean UI

Premium infrastructure/construction feel

Use a combination of dark blue, white, grey, and subtle orange accents

Large high-quality infrastructure/construction images

Smooth animations and hover effects

Fully responsive for desktop, tablet, and mobile

Easy-to-use navigation

Professional typography

Avoid an overly complicated design

Important Requirements

Do NOT invent real company statistics, employee information, project information, phone numbers, or email addresses.

Use clearly marked placeholder information wherever real information is unavailable.

Make all content editable.

Use realistic infrastructure images as placeholders.

Make the website SEO-friendly.

Optimize page loading speed.

Add accessibility features.

Ensure the website works perfectly on mobile devices.

Add subtle scroll animations.

Use professional icons.

Include a CMS-style structure so HR/admin users can easily update jobs, announcements, projects, and news.

Special HR Feature

Create an HR Dashboard that can be accessed after login.

Dashboard sections:

Employee Management

Job Applications

The HR dashboard should have a clean admin-panel design with charts and tables.

Overall Experience

The final website should look like the website of a large, established Indian infrastructure company—professional, trustworthy, modern, and suitable for corporate clients and employees.

Prioritize:
Trust + Infrastructure + Innovation + Sustainability + People + Careers.
